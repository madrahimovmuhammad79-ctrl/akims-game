# 🪙 AKIM'S GAME

Простая и красивая кликер-игра на чистом HTML + CSS + JavaScript.

Тапай по монете, зарабатывай монеты и покупай улучшения!

---

## 🎮 Как играть

1. Тапай по большой монете в центре экрана
2. Зарабатывай монеты
3. Покупай улучшения в магазине
4. Становись богаче и быстрее

---

## ✨ Особенности

- Красивый тёмный интерфейс
- Плавные анимации
- Адаптивный дизайн (удобно на телефоне)
- Прогресс сохраняется в `localStorage`
- Кнопка сброса прогресса

---

## 🚀 Как запустить

Просто открой файл `index.html` в любом современном браузере.

Никаких установок и зависимостей не требуется.

---

## 🛠 Технологии

- HTML5
- CSS3 (CSS Variables, Grid, Flexbox)
- Vanilla JavaScript
